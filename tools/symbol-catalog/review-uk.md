# Українські назви: що перевірити

Список назв каталогу знаків APP-6D / MIL-STD-2525D, у перекладі яких немає певності.
Назви лежать у `tools/symbol-catalog/uk.json` (ключ → [English, українською]); після правки
треба перегенерувати Dart-дані (`tools/symbol-catalog/README.md`) і прибрати рядок звідси.

Ключ: `SS:EEEEEE` — знак (набір, код сутності), `SS:mN:CC` — модифікатор сектора N,
`SS:xxxxCC` — спеціальний підтип, `set:`, `identity:`, `status:`, `hqtfd:`, `amp:` — службові таблиці.
«термін» у останній колонці означає сумнів у виборі терміна загалом; у дужках — підказка
щодо значення.

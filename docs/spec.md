# Горизонталь: спецификация

12.10.2026 · Евгений Лавриненко (Synckord)

## Обзор и принципы

Горизонталь (Horyzontal) это бесплатное open source приложение для работы с картами и координатами на iOS и Android, функционально повторяющее платный «Топик» ($11.99, только iOS). Целевая аудитория: военные, геодезисты, спасатели, все, кто работает с топокартами в поле.

- **Лицензия:** GPL-3.0. Код на GitHub, сборки в App Store, Google Play и APK в GitHub Releases.
- **Бренд:** Synckord, bundle id `com.synckord.horyzontal`.
- **Платформы:** Flutter, iOS 17+, Android 8+ (API 26), телефоны и планшеты.
- **Язык на старте:** только украинский, строки сразу вынесены в ARB для будущего перевода.
- **Офлайн-first:** всё, кроме загрузки тайлов и пакетов карт, работает без сети.
- **Никаких сетевых запросов, кроме тайлов и пакетов карт.** Нет аналитики, крэш-репортинга, аккаунтов, серверов, телеметрии.
- **Что не копируем:** код, иконку, название, графику и тексты «Топика». Повторяем только функциональность.

## Функционал

Приложение повторяет все функции «Топика» по описанию и истории версий, плюс несколько расширений (отмечены \*). Пять вкладок: Мапа, Журнал, Завдання, Компас, Налаштування.

| Задачи | ПГЗ и ОГЗ с выбором системы координат и формата углов (на плоскости в прямоугольных координатах и на эллипсоиде\*); угол Солнца и Луны на заданное время и место с таймером обратного отсчета, без ограничения по годам\* | 1, 4 |

| Обмен | Отправка координат текстом в нужном формате; QR для точек; передача слоев по Wi-Fi; импорт и экспорт файлов; совместимость с ATAK | 2 |

## Карты и высоты

Все источники по умолчанию бесплатные и легальные для открытого проекта; хостинг офлайн-пакетов бесплатный через GitHub Releases.

| Слой | Источник | Как попадает в приложение |
| --- | --- | --- |
| Онлайн-карта | [OpenFreeMap](https://www.github.com/hyperknot/openfreemap), векторные тайлы OpenStreetMap, без ключей и лимитов | Прямые запросы тайлов с кэшем на устройстве |
| Офлайн-карты | Ежедневная сборка [Protomaps Basemap](https://docs.protomaps.com/basemaps/downloads) (OpenStreetMap, ODbL) | GitHub Actions раз в месяц делает `pmtiles extract` по полигону каждой из 25 областей и кладет PMTiles в GitHub Releases; приложение качает пакет по выбору области |
| Высоты | [Copernicus DEM GLO-30](https://registry.opendata.aws/copernicus-dem/), 30 м, AWS без аккаунта | Тот же пайплайн нарезает высоты по областям в terrain-RGB PMTiles, пакет качается вместе с картой области |
| Спутник и прочее | Любой XYZ/TMS-источник по URL, добавленный пользователем | Онлайн с кэшем и загрузкой области; ответственность за условия источника на пользователе, в репозитории URL Google/Esri нет |
| Свои карты | Файлы пользователя: MBTiles, PMTiles, GeoTIFF (например, сканы топокарт) | Импорт через «Файлы» или «Поделиться» |

Детали:

- Copernicus это модель поверхности (DSM): учитывает лес и здания. Для видимости между антеннами это плюс, в интерфейсе помечаем, что высота включает растительность.
- Protomaps просит не хотлинкить их сборки, поэтому приложение ходит только в наши GitHub Releases.
- Размер пакета области оцениваем в спайке; если область целиком тяжелая, режем максимальный зум или делим на части.
- Атрибуция OpenStreetMap, OpenFreeMap и Copernicus на экране карты и в «О приложении».

## Обмен данными

Обмен идет без интернета: точки через QR, слои по прямому Wi-Fi между устройствами, всё остальное файлами через «Поделиться».

### QR для точек

- Один QR = одна точка: координаты, название, код символа APP-6 (SIDC), позывной, короткое описание.
- Компактный формат `horyzontal://p?...`, плюс MGRS в читаемом виде, чтобы обычный сканер тоже показал координаты.
- Сканер встроен в приложение, принятая точка попадает в выбранный слой.

### Слои по Wi-Fi

iOS не умеет программно поднимать точку доступа, поэтому роль хоста выбирается по паре платформ, а направление передачи от роли не зависит.

| Пара устройств | Кто хост | Как соединяются |
| --- | --- | --- |
| Android и Android | Любой | Хост поднимает LocalOnlyHotspot (API 26+), второй подключается через WifiNetworkSpecifier (Android 10+) или legacy API на 8-9 |
| Android и iPhone | Всегда Android | iPhone подключается к точке Android через NEHotspotConfiguration (системный запрос «Подключиться?») |
| iPhone и iPhone | Не нужен | Multipeer Connectivity: прямое соединение по Wi-Fi/Bluetooth без точки доступа |

Сценарий:

1. Отправитель выбирает слои и жмет «Передать по Wi-Fi».
2. Хост поднимает точку и показывает QR: SSID, пароль, адрес и порт, одноразовый ключ 256 бит.
3. Второе устройство сканирует QR и подключается автоматически.
4. Передача по TCP с шифрованием AES-256-GCM на ключе из QR; без этого ключа данные не прочитать, даже находясь в той же сети.
5. Получатель видит список слоев и подтверждает импорт; точка доступа гаснет.

### Файлы и совместимость

- Свой формат: версионированный JSON (`.hrz`), слои с объектами, полилиниями и полигонами.
- KML/KMZ и GPX: импорт и экспорт.
- ATAK: точки в Cursor-on-Target (CoT XML), слои в KMZ data package, импорт и экспорт.
- Отправка через системное «Поделиться»: Signal, Telegram, AirDrop, «Файлы».
- Отправка координат текстом в выбранной системе и формате.
- Импорт JSON «Топика» позже, когда появится образец файла.

## Безопасность и приватность

Данные пользователя никогда не покидают устройство без его явного действия, а на устройстве хранятся зашифрованными.

- **Вход:** PIN (6 цифр) и Face ID/Touch ID/отпечаток; блокировка после ухода в фон через настраиваемое время.
- **Шифрование:** база SQLite через SQLCipher (AES-256), ключ в Keychain (iOS) и Android Keystore; файлы экспорта шифруются опционально паролем.
- **Переключатель приложений:** экран размывается при уходе в фон; на Android опция FLAG_SECURE (запрет скриншотов).
- **Экстренное удаление:** кнопка в настройках, подтверждение удержанием 3 секунды; стирает базу, ключ шифрования, кэш тайлов и настройки; офлайн-пакеты карт по отдельной галочке.
- **Сетевая политика:** в коде есть только запросы к OpenFreeMap, GitHub Releases с пакетами и источникам тайлов, которые добавил сам пользователь. Никаких SDK аналитики, рекламы и крэш-репортинга (включая Firebase). Белый список доменов зафиксирован в README, и CI проверяет, что новые домены не появились.
- **Утечка района через тайлы:** запросы онлайн-тайлов выдают провайдеру примерный район. В настройках режим «Только офлайн» полностью отключает сеть; в README и при первом запуске объясняем риск.
- **Геолокация:** только когда приложение открыто, без фонового доступа.

## Технический стек и архитектура

Flutter-приложение с ядром геодезии в отдельном чистом Dart-пакете, который покрыт тестами и может жить самостоятельно.

| Задача | Решение |
| --- | --- |
| Состояние и навигация | Riverpod, go_router |
| База | Drift (SQLite) + SQLCipher, ключ через flutter_secure_storage |
| Карта | MapLibre Native через Flutter-плагин (maplibre_gl или maplibre, выбор после спайка с PMTiles и рельефом) |
| Системы координат | Своя реализация в `horyzontal_geo`: Гельмерт 7 параметров, поперечный Меркатор по рядам Крюгера 6-го порядка (Karney 2011), MGRS/UTM. Вместо proj4dart: точнее, без зависимостей (решение этапа 1) |
| Геодезия | Порт GeographicLib (Karney) для эллипсоида; плоские ПГЗ/ОГЗ в Гаусс-Крюгере своим кодом |
| Символы APP-6 | Порт milsymbol (MIT) в Dart, рендер SVG через flutter_svg; коды SIDC APP-6D; названия и поиск — каталог по Esri JMSML (Apache-2.0) с украинским переводом |
| Компас и склонение | sensors_plus или flutter_compass; модель WMM (NOAA, public domain) своим кодом |
| Солнце и Луна | Алгоритмы Меёса своим кодом или порт suncalc (BSD) |
| QR | qr_flutter для генерации; сканирование через ZXing (flutter_zxing, zxing-cpp) на обеих платформах (с этапа 3; раньше стоял mobile_scanner с Google ML Kit, который отправляет в Google метрики использования) |
| Wi-Fi обмен | Платформенные каналы: Kotlin (LocalOnlyHotspot, WifiNetworkSpecifier), Swift (NEHotspotConfiguration, MultipeerConnectivity); шифрование через пакет cryptography |
| Вход | local_auth (биометрия), свой экран PIN |
| Файлы и форматы | share_plus, file_picker, xml (KML, GPX, CoT), archive (KMZ) |
| Геолокация и маршрут | geolocator; url_launcher для Apple Maps и Google Maps |
| Локализация | ARB + flutter_localizations, только uk на старте |
| CI/CD | GitHub Actions: тесты, сборки, fastlane в сторы, ежемесячный пайплайн карт (pmtiles CLI, GDAL для высот) |

Структура репозитория:

- `packages/horyzontal_geo`: координаты, геодезия, углы, Солнце/Луна, WMM. Чистый Dart, без Flutter.
- `packages/horyzontal_symbols`: APP-6.
- `app/lib/features/`: map, journal, tasks, compass, exchange, settings, security.
- `tools/map-pipeline/`: скрипты нарезки областей и высот, полигоны областей в GeoJSON.

Главный критерий качества: каждая конвертация и задача в `horyzontal_geo` сверяется тестами с эталонными значениями из официальных или широко признанных конвертеров, с допуском не больше 1 м.

## Этапы разработки

Четыре этапа по согласованному порядку плюс короткий спайк в начале, чтобы снять технические риски до основной работы.

0. **Спайк (рискованные места).** MapLibre-плагин с офлайн PMTiles и рельефом на iOS и Android; размер пакета одной области; передача файла Android-хост и iPhone по LocalOnlyHotspot. Готово, когда все три работают на реальных устройствах.
1. **Координаты, конвертер, компас.** Пакет `horyzontal_geo` с тестами, конвертер координат и углов, компас, ПГЗ/ОГЗ в базовом виде, PIN и шифрование базы. Готово, когда эталонные тесты зеленые и это уже можно выложить в TestFlight как самостоятельный конвертер.
2. **Карта и объекты.** Онлайн и офлайн карты, загрузка областей, объекты APP-6 с конструктором, слои, журнал, импорт/экспорт (JSON, KML, GPX, CoT), QR для точек, Wi-Fi обмен, экстренное удаление. Готово, когда можно полностью заменить «Топик» в базовом сценарии. Первый публичный релиз в App Store и Google Play.
3. **Инструменты.** ПГЗ/ОГЗ со всеми системами и форматами, линейка, полилинии, полигоны, профиль высот, видимость с высотой мачт. Замена сканера QR mobile_scanner → ZXing (flutter_zxing): убирает Google ML Kit и его телеметрию, открывает путь в F-Droid.
4. **Расширения.** Тепловая карта высот, Солнце и Луна с таймером, кластеризация, свои источники тайлов, планшетная раскладка.

## Открытые вопросы и риски

Главный технический риск это точность СК-42 и УСК-2000; главный продуктовый риск это размер офлайн-пакетов.

- [ ] Зарезервировать имя «Горизонталь» в App Store Connect и Google Play Console
- [x] Параметры перехода к WGS84: единого официального набора для СК-42 нет, взят EPSG:15865 (область действия включает Украину); УСК-2000 — EPSG:7817. Эталоны — PROJ и GeographicLib, см. `tools/geo-reference/README.md`
- [x] Измерить размер пакета области (карта + высоты) в спайке и решить, резать ли зум
- [ ] Получить образец JSON-экспорта «Топика» для импорта
- [x] Решить, куда ведет кнопка донатов: банка monobank (ссылка задается при сборке, `DONATE_URL`)

Риски:

- **OpenFreeMap** держится на донатах и одном публичном инстансе. Запасной вариант: онлайн-режим поверх наших же PMTiles из GitHub Releases.
- **Wi-Fi обмен:** на Android 13+ нужно разрешение NEARBY_WIFI_DEVICES, на старых версиях включенная геолокация; на iOS capability Hotspot Configuration. Поведение разных прошивок Android проверяем на 3-4 реальных устройствах.
- **GitHub Releases:** лимит 2 ГБ на файл, большие области делим на части.
- **Сканер QR:** закрыто на этапе 3. mobile_scanner на Android тянул Google ML Kit, а тот отправляет в Google метрики использования ([раскрытие данных ML Kit](https://developers.google.com/ml-kit/android-data-disclosure)); сканер заменен на ZXing (flutter_zxing), CI не дает ML Kit вернуться.
- **F-Droid и Google Play Services:** geolocator на Android тянет play-services-location. Телеметрии в нем нет, но для F-Droid нужен вариант без Play Services.
- **Магнитный компас** на телефонах дает ошибку в несколько градусов; в интерфейсе показываем точность датчика и предупреждаем о калибровке.
